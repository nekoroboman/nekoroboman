# 本部タスク（ネコロボマン本部のタスク管理）

Google ToDo リストと同じ操作感のタスク管理アプリです。次の機能を足しています。

- **誰が・いつまでに・何を** の3つを入れないと登録できない
- **進捗管理**: ステータス（未着手・進行中・完了）、最新状況の入力（日時・名前つきで残る）、進捗ボード
- **毎時のメール通知**: 平日 10:00〜17:00 の毎時ちょうどに本部全体の状況を送り、17:30 に「今日のまとめ」を送る（時刻は画面で変えられる）
- **同じアカウントを何人かで同時に使っても大丈夫**: ほかの人の変更が、その瞬間に全員の画面に出る

| 置き場所 | 中身 |
|---|---|
| 画面 | GitHub Pages（このリポジトリの `web/`） |
| データ・ログイン・リアルタイム通知 | Supabase（東京） |
| メール送信 | 共有 Gmail から送る小さな GAS（`gas-relay/`） |

設計の理由は [構成の設計](docs/architecture.md)、機能の一覧は [要件定義書](docs/requirements.md) にあります。

## 使い始めるまで（最初の1回だけ・15分くらい）

### 1. 画面を公開する（GitHub の設定で1回だけ）

1. このリポジトリの「Settings」→ 左の「Pages」を開く
2. 「Build and deployment」の Source を **Deploy from a branch** にする
3. Branch を **`claude/sharp-rubin-aspw3s`**、フォルダを **`/ (root)`** にして「Save」
   - 本番のブランチ（main）に取り込んだあとは、ここを `main` に変える
4. 数分たつと、画面が次の URL で開けるようになる

   **https://nekoroboman.github.io/nekoroboman/web/**

### 2. ログインを作る

1. 上の URL を開き、「はじめての方（共有アカウントのパスワードを決める）」を押す
2. 本部の共有アカウントのメールアドレスと、これから使うパスワード（8文字以上）を入れて「設定してログイン」
   - 登録できるのは本部の共有アカウントのアドレスだけです
3. 次から本部のパソコン・スマホでは、このメールアドレスとパスワードでログインする（一度ログインすれば、その端末ではログインしたままになる）

### 3. メンバーとメールの設定

1. 「操作する人を選んでください」と出るので、自分の名前を入れて「追加して選ぶ」
   - みんなで同じアカウントを使うので、**誰が操作したかを記録するために**端末ごとに名前を選びます。右上でいつでも切り替えられます
2. 右上の歯車 →「メンバー」で、本部の人を全員追加
3. 歯車 →「メール通知」で、送信先のアドレスを入れて「1時間に1回…送る」をオンにして「保存」

### 4. メール送信用の GAS を置く（共有アカウントで）

1. Google ドライブの「本部タスク メール送信用GAS（貼り付け用）」を開き、中身を全部コピーする（合言葉が入った状態で用意してあります）
2. https://script.google.com で「新しいプロジェクト」を作り、「コード.gs」の中身を全部消して貼り付け、保存
3. 関数の選びボックスで **`setup`** を選んで「実行」→「権限を確認」→ 共有アカウント →「詳細」→「（安全ではないページ）に移動」→「許可」
4. 本部タスクの歯車 →「メール通知」に「メール送信用の GAS は動いています」と出れば OK。「保存してテスト送信」で、1分以内にメールが届くか確認する

## 使い方のポイント

| やりたいこと | 操作 |
|---|---|
| タスクを登録 | リストの「タスクを追加」か、左上の「作成」。タイトル・期限・担当者を選んで Enter |
| 進み具合を書く | タスクを開いて「最新状況」に書いて「記録する」。未着手なら自動で「進行中」になる |
| 完了にする | 丸いチェックを押す。下の「元に戻す」で取り消せる |
| 期限を延ばす | タスクを開いて期限を変える。理由を残す欄が出る（任意） |
| 全体の状況を見る | 左の「進捗ボード」 |
| 自分の分だけ見る | 左の「自分の担当」 |
| 消したタスクを戻す | 左の「ごみ箱」（30日間戻せる） |

- タスク名や最新状況に、**利用者さんの名前などの個人情報は書かないでください**（メールで社外のサーバーを通るため）
- Gmail の無料アカウントは、メールを1日100通（宛先の数で数えます）まで送れます。最初の設定（1日9回）なら、宛先は11件までにしてください

## よくある困りごと

| 困りごと | 直し方 |
|---|---|
| ログインできない | メールアドレスとパスワードを確認。パスワードを忘れたら、Supabase の管理画面（Authentication → Users）で変更する |
| 「このアカウントでは使えません」と出る | 本部の共有アカウント以外でログインしている。右下の「ログアウト」から入り直す |
| メールが届かない | 歯車 →「メール通知」を見る。「メール送信用の GAS が動いていない」と出たら、手順4をやり直す |
| 画面が古いまま | 自動で最新になります。右上が「オフライン」のときは通信を確認 |

## 開発者向け

```
web/            … 画面（GitHub Pages で公開）
  app.js          画面の動き（Preact）。データは Supabase の api_* 関数で読み書きする
  styles.css      見た目
  config.js       つなぎ先（公開してよいキーだけ）
  vendor/         画面の部品（Supabase JS・htm/Preact・Material アイコン。同梱）
supabase/
  migrations/     データベース（表・守り・api_* 関数・リアルタイム通知）
  functions/
    mail/           毎時メールの中身を作る（送信用 GAS とプレビューから呼ばれる）
    account-setup/  最初の1回だけ、共有アカウントのログインを作る
gas-relay/      … メール送信用の小さな GAS（合言葉は入っていない。貼り付け用はドライブにある）
gas/ dist/      … 旧版（スプレッドシート版）。使わない
dev/            … 動作確認用（試験用サーバー・テスト）
docs/           … 要件定義書・構成の設計
```

```bash
node dev/test-server.js           # 旧版（GAS）のサーバー側テスト
node dev/web-server.js 8095       # 画面の試験用サーバー（Supabase の代わりに試験用のデータで動く）
WEB=1 BASE=http://localhost:8095/ node dev/e2e.js   # 画面のテスト（ログイン・2人同時操作を含む。要 Playwright）
```
