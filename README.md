# 本部タスク（ネコロボマン本部のタスク管理）

Google ToDo リストと同じ操作感のタスク管理アプリです。次の機能を足しています。

- **誰が・いつまでに・何を** の3つを入れないと登録できない
- **進捗管理**: ステータス（未着手・進行中・完了）、最新状況の入力（日時・名前つきで残る）、進捗ボード
- **毎時のメール通知**: 本部全体のタスク状況を、設定したアドレスに1時間に1回送る
- **同じアカウントを何人かで同時に使っても大丈夫**: ほかの人の変更が数秒で全員の画面に出る

Google スプレッドシートと Apps Script（GAS）だけで動くので、サーバーの契約は要りません。

詳しい中身は [要件定義書](docs/requirements.md) を見てください。

## 導入手順（30分くらい）

本部の**共有の Google アカウント**でログインした状態で行います。

### 1. データ用のスプレッドシートを作る

1. Google ドライブで「新規」→「Google スプレッドシート」を作る
2. 名前を「本部タスク（データ）」にする

### 2. プログラムを貼り付ける

1. スプレッドシートのメニュー「拡張機能」→「Apps Script」を開く
2. 左の「コード.gs」を開き、中身を全部消して、[dist/Code.gs](dist/Code.gs) の中身を**全部**貼り付ける
3. 左の「ファイル」の「＋」→「HTML」を押し、名前を **`Index`** にする（`.html` は自動で付きます）
4. できた「Index.html」の中身を全部消して、[dist/Index.html](dist/Index.html) の中身を**全部**貼り付ける
5. 上の「保存」（フロッピーのマーク）を押す

> GitHub のファイルを開いて、右上の「Raw」を押すと文字だけの画面になります。そこで全部選択（Ctrl+A／⌘+A）してコピーすると確実です。

### 3. 最初の設定を実行する

1. 上の関数の選びボックスで **`setup`** を選び、「実行」を押す
2. 「承認が必要です」と出たら「権限を確認」→ 共有アカウントを選ぶ
3. 「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」→「許可」
   - 自分たちで作ったアプリなので、この表示が出るのは正常です
4. 下の「実行ログ」に「準備ができました」と出れば OK。スプレッドシートに「タスク」「メンバー」などのシートができています

`setup` は、データ用のシートの作成、最初のリスト「マイタスク」の作成、5分ごとの自動実行（毎時メールの送信）の設定をします。2回実行しても大丈夫です。

### 4. ウェブアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」
2. 歯車マーク →「ウェブアプリ」を選ぶ
3. 次のように設定して「デプロイ」
   - 説明: 本部タスク
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **自分のみ**（共有アカウントでログインした人だけが使えます）
4. 表示された「ウェブアプリの URL」（`https://script.google.com/macros/s/…/exec`）をコピーする
5. その URL を、本部のパソコン・スマホのブックマーク（ホーム画面）に登録する

### 5. 使い始める

1. 共有アカウントでログインしたブラウザで URL を開く
2. 「操作する人を選んでください」と出るので、自分の名前を入れて「追加して選ぶ」
   - みんな同じアカウントを使うので、**誰が操作したかを記録するために**端末ごとに名前を選びます。右上でいつでも切り替えられます
3. 右上の歯車 →「メンバー」で、本部の人を全員追加する
4. 歯車 →「メール通知」で、送信先のアドレスを入れて「1時間に1回…送る」をオンにし、「保存してテスト送信」でメールが届くか確認する

## 使い方のポイント

| やりたいこと | 操作 |
|---|---|
| タスクを登録 | リストの「タスクを追加」か、左上の「作成」。タイトル・期限・担当者を選んで Enter |
| 進み具合を書く | タスクを開いて「最新状況」に書いて「記録する」。未着手なら自動で「進行中」になる |
| 完了にする | 丸いチェックを押す。下の「元に戻す」で取り消せる |
| 期限を延ばす | タスクを開いて期限を変える。理由を残す欄が出る（任意） |
| 全体の状況を見る | 左の「進捗ボード」。期限切れ・今日まで・担当者別の数が見られる |
| 自分の分だけ見る | 左の「自分の担当」 |
| 消したタスクを戻す | 左の「ごみ箱」（30日間残ります） |

- タスク名や最新状況に、**利用者さんの名前などの個人情報は書かないでください**（メールで社外のサーバーを通るため）
- Gmail の無料アカウントは、メールを1日100通（宛先の数で数えます）まで送れます。平日9時〜18時の毎時（1日10回）なら、宛先は9件までにしてください

## プログラムを直したとき

1. Apps Script の中身を新しい `dist/Code.gs`・`dist/Index.html` に貼り替えて保存
2. 「デプロイ」→「デプロイを管理」→ 鉛筆マーク →「バージョン」を「新バージョン」にして「デプロイ」
   - こうすると URL は変わりません（「新しいデプロイ」にすると URL が変わります）

## よくある困りごと

| 困りごと | 直し方 |
|---|---|
| 「読み込めませんでした」「ファイルを開くことができません」と出る | 共有アカウントでログインしているか確認。ブラウザで複数の Google アカウントにログインしていると開けないことがあります。Chrome なら共有アカウント専用の「プロフィール」を作ると確実です |
| 毎回「操作する人」を聞かれる | ブラウザの設定で、サイトのデータ（Cookie）を消さない設定にする |
| メールが届かない | 歯車 →「メール通知」の送信履歴を見る。「自動実行が設定されていません」と出たら、そこのボタンを押す |
| 画面が古いまま | 自動で数秒ごとに最新になります。右上が「オフライン」のときは通信を確認 |

## 開発者向け

```
gas/            … プログラムの元（ここを直す）
  Code.gs         画面の表示・呼び出しの窓口・最初の設定
  Db.gs           データの保存と、最新情報を反映するしくみ（同期番号）
  Api.gs          リスト・タスク・最新状況・メンバーの操作
  Mail.gs         毎時メール・祝日・ごみ箱の片付け
  Index.html      画面の入れ物
  Styles.html     見た目
  App.html        画面の動き（Preact）
  Vendor.html     画面の部品（htm/Preact・Material アイコン。同梱）
dist/           … 貼り付け用に2ファイルにまとめたもの（node dev/build.js で作る）
dev/            … 動作確認用（GAS の代わりをする試験用サーバー・テスト）
docs/           … 要件定義書
```

```bash
node dev/build.js                 # dist/ を作り直す
node dev/test-server.js           # サーバー側のテスト
node dev/server.js 8080           # 試験用サーバー（http://localhost:8080/）
node dev/e2e.js                   # 画面のテスト（2人同時操作を含む。要 Playwright）
DIST=1 node dev/test-server.js    # まとめた dist/ でテスト
```
