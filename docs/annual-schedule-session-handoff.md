## 3. 今あるもの（試作）

### 画面

| 画面 | できること |
|---|---|
| サイト版 `index.html` | 年度の切り替え（‹ ›・選択・`#fy=2026`）、今月・来月の予定、12か月のカード（研修①必須・研修②・委員会）、研修／委員会の表示切り替え、PDF のダウンロード、データの出どころの表示 |
| PDF版 `print.html` | A4縦1枚。月・研修項目①（必須研修）・研修項目②・委員会（本部標準）・管理者確認の欄。事業所名・管理者の記入欄、出力日 |

### データの流れ（試作）

```
ウェルビー研修計画のスプシ（年度ごとにシートが増える）─┐
                                                     ├→ GAS（gas/Code.gs）→ JSON → index.html / print.html
委員会議事録キットの「委員会マスタ」────────────────┘   （つながらないときは data/ の同梱データ）
```

- GAS は全シートを見て、「研修項目①」「研修項目②」の見出しがある表を年度ごとに読む（年度は見出し行 → 上3行 → シート名の順に探す）
- 5分のキャッシュ。`?debug=1` でどのシートを読んだかを返す

### 元のデータ（構造だけ。中身・ID・個人情報はここに書かない）

| もの | 形 | 注意 |
|---|---|---|
| ウェルビー研修計画（スプシ） | 年度ごとにシート。列: 年度（縦に結合）／月／研修項目①（必須研修）／研修項目②／視聴内容①（2列結合）／視聴内容② | ユーザーが示したスプシは前のセッションから開けなかった。試作は Drive にあった店舗別「研修計画」シート（同じ形）から作った |
| 委員会議事録キット（GAS アプリのスプシ） | シート: **委員会マスタ**（年度・委員会名・開催予定月）／**年間スケジュール**（年度 × 4月〜3月、セルに委員会名）／**実施報告**（送信日時・年度・法人名・店舗名・委員会名・回覧板サイン完了）／**履歴**（作成日時・開催日・法人・店舗・委員会・委員長・出席者数・議題数・議事録PDF）／**視聴状況チェック**（法人・店舗 × 委員会ごとの「議事録」「サイン」）／**未実施レポート**／**_法人マスタ**（表示名・法人名・店舗名・店舗スプシURL・在職者範囲）／**認証**（法人・店舗・OPEN日・期限） | 委員長名などの個人情報が入っている。構造だけ使う |

## 4. 試作で決めたこと

- 年度は4月始まり。表示は令和（西暦 − 2018）
- 研修は毎月2本。①が必須研修、②がもう1本。どちらもウェルビーの「必須研修」から視聴 → 研修テスト・感想 →「済」
- 委員会は本部標準（委員会マスタ）の月を出す。店ごとにずらした月は出していない
- PDF は A4縦1枚で、事業所名・管理者・管理者確認の欄をつける
- 公開リポジトリに、スプシの ID・個人情報は入れていない

## 6. 管理側（本部）の画面・機能の候補（設計メモのたたき台に）

| 画面 | 使う人 | できること |
|---|---|---|
| 年度の研修計画 | 本部 | 年度を作る（前年度から複製）、月ごとに研修①②（研修項目・動画名）を入れる・直す、スプシ／xlsx から取り込む、下書き → 加盟店に公開 |
| 委員会の標準スケジュール | 本部 | 年度ごとの委員会名と開催月（W5 との分担しだい） |
| 加盟店ごとのずらし | 本部 | 店ごとに委員会の月をずらす（委員会アプリ v3 の考え方） |
| PDF の発行 | 本部 | 年度ごとに A4 1枚を作って全店に配る（事業所名を差し込むかは7章の5） |
| 実施状況 | 本部 | 研修の視聴率（月 × 店）、委員会の実施（議事録・サイン）を一覧し、要対応の店を出す |
| 加盟店の画面 | 加盟店 | 自店の年間スケジュール・今月の予定・PDF。ホームの「やること」に今月の研修・委員会を出す |

## 7. 決めること（ユーザーに聞く）

1. **担当表の ID**: 新しい行（W22 年間スケジュール）にするか、W5 委員会・W12 研修ライブラリのどちらかに入れるか（おすすめ: W22 を作り、委員会の中身は W5 から読む）
2. 研修計画の入れ方: 本部が画面で入力するか、当面はスプシの取り込みか
3. 委員会の標準スケジュールの持ち主: W5 か、こちらか
4. 店ごとのずらし: 本部だけが直すか、加盟店からも変更を出せるか
5. PDF: 全店共通の1枚か、事業所名入りで店ごとか
6. ウェルビーの視聴率・研修実施報告の取り込みをどこまでやるか（全体設計では P3）
7. 委員会マスタの2027年度分は、身体拘束・虐待防止の第1回が1月、第2回が7月。4月始まりで並べると第2回が先になる。2027年度だけ1月〜12月で数えているのか
8. 令和8年度の研修②で、7月と2月が同じ動画（緊急時の対応【1】基本原則と心構え）。これでよいか
9. 令和8年度12月の研修②: 10/30 のローカルのセッション「ウェルビーラーニング年間予定」で「食中毒 → カスタマーハラスメント」に変わった記録がある。試作の同梱データは食中毒のまま。元のスプシで確かめる
