# 年間スケジュール（ウェルビーラーニング研修・委員会）

ウェルビーラーニングの年間研修計画と、委員会の標準スケジュールを年度ごとに表示する。

- **サイト版** `index.html` … 年度を切り替えて何年分でも見られる（`index.html#fy=2026` で年度を指定）
- **PDF版** `print.html` … 事業所で掲示・保管する A4縦1枚（`print.html#fy=2026`）

## 仕組み

```
ウェルビー研修計画のスプレッドシート ─┐
  （年度ごとにシートを追加）          ├─ gas/Code.gs（ウェブアプリ）─ JSON ─→ index.html / print.html
委員会議事録キットの「委員会マスタ」 ─┘                                     （つながらないときは data/ の同梱データ）
```

- ウェルビー研修計画は**全シートを自動で読む**ので、新しい年度のシートを足せばサイトとPDFに出る
- 委員会は「委員会マスタ」の行（年度・委員会名・開催予定月）を読む。店舗ごとにずらした月ではなく本部標準
- スプレッドシートを直してから反映されるまで最大5分（すぐ出したいときは GAS エディタで `clearCache` を実行）

| ファイル | 内容 |
| --- | --- |
| `index.html` / `print.html` | サイト版 / PDF版 |
| `config.js` | GAS ウェブアプリの URL（`apiUrl`） |
| `assets/calendar.js` | 両ページ共通の処理（データ取得・年度計算など） |
| `gas/Code.gs` | スプレッドシートを読んで JSON を返す Google Apps Script |
| `data/wellbe-learning.js`, `data/committees.js` | 同梱データ（連携できないときの予備） |
| `pdf/schedule-<年度>.pdf`, `pdf/index.js` | 書き出したPDFと、その一覧 |
| `tools/make-pdf.js` | `print.html` からPDFを書き出すツール |

## はじめの設定（1回だけ）

1. [script.google.com](https://script.google.com) で新しいプロジェクトを作り、`gas/Code.gs` の中身を貼り付ける
2. プロジェクトの設定 → スクリプト プロパティ に2つ登録する
   - `WELLBE_SPREADSHEET_ID` … ウェルビー研修計画のスプレッドシートID（URLの `/d/` と `/edit` の間）
   - `COMMITTEE_SPREADSHEET_ID` … 委員会議事録キットのスプレッドシートID
3. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」、次のユーザーとして実行「自分」、アクセスできるユーザー「全員」
4. 発行された URL の末尾に `?debug=1` を付けて開き、`log` で各シートが読めているか確認する
5. URL（`…/exec`）を `config.js` の `apiUrl` に貼る

アクセス「全員」にすると、URL を知っている人は研修名・委員会名・開催月を見られる（個人情報は返さない）。

## 新しい年度を足す

- **ウェルビー研修**: スプレッドシートに新しいシートを足す。読み取りの条件は次のとおり
  - 見出し行に「研修項目①」「研修項目②」がある（「視聴内容①」「視聴内容②」「月」もあれば読む）
  - 年度は、見出し行の中 → 見出し行の上3行 → シート名 の順に「令和9年度」「2027年度」「R9」を探す
  - 1枚のシートに複数年度の表があってもよい
- **委員会**: 委員会マスタに行を足す（委員会議事録キットの「年度を追加」と同じ）
- **PDF**: `print.html` をブラウザで開いて「印刷 / PDFに保存」、または `node nekorobo-calendar/tools/make-pdf.js`（今年度。`2027` や `all` も指定できる）

## データの出典（同梱データ）

- ウェルビー研修：令和8年度、令和7年度（12月〜3月）… Google ドライブの店舗別「研修計画」シート（本部作成）
- 委員会：委員会議事録キットの「委員会マスタ」
